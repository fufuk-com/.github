## 📖 關於 A-Fu Design

**A-Fu Design Studio** 致力於將創新構想轉化為極致的數位產品。我們專注於 **高效能網頁設計**、**iOS / Android 手機 APP 開發**、**企業級客製化軟體系統** 與 **Chrome 瀏覽器擴充功能**。

本 GitHub 組織與儲存庫集合收錄了 A-Fu Design 的核心品牌主站、數位生態系子平台，以及一系列瀏覽器擴充外掛與開發工具。

## 🧩 瀏覽器擴充功能與應用專案 (Chrome Extensions & Projects)

本儲存庫集包含多款專注於提升生產力與使用者體驗的瀏覽器外掛與工具專案：

- 🌌 **[Aether-Tab](https://github.com/topics/chrome-extension)** — 美化與高生產力的新分頁 (New Tab Chrome Extension)，整合極簡視覺與常用工具。
- 🎨 **[DesignTokenExtractor](https://github.com/topics/design-tokens)** — 設計系統 Token 自動化擷取工具，協助設計師與前端工程師快速同步視覺樣式。
- ✍️ **[MarkSense](https://github.com/topics/web-annotation)** — 智慧網頁標記與筆記感知工具，讓瀏覽過程中的資訊收集更具系統性。
- 🎮 **[PokeCounter](https://github.com/topics/counter-app)** — 寶可夢 / 計數器互動工具，提供流暢輕巧的計數與數據記錄功能。

## 🛠️ 技術棧與架構 (Technologies & Architecture)

- **前端視覺與體驗 (Frontend & UI/UX)**:
  - HTML5, Vanilla CSS (Glassmorphic Design + Animated Mesh Gradient)
  - ES6+ JavaScript, 原生 i18n 國際化引擎 (支援 10 國語系)
  - Responsive Web Design (RWD), PWA, Single Page Application (SPA)
- **雲端與 Serverless 基礎架構 (Cloud Infrastructure)**:
  - Cloudflare Pages & Cloudflare Workers Global CDN
  - AWS, GCP, Azure 公有雲架構
  - RESTful API & GraphQL 介面設計
- **企業客製與資料庫 (Enterprise Systems)**:
  - Ragic Enterprise Cloud Database (ERP / CRM / 客製化工作流)
  - Chrome Extension Manifest V3 架構開發
